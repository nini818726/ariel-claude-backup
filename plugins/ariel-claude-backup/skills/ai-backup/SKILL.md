# Claude 备份 / 恢复（ariel-claude-backup）

所有工作都由本 skill 目录下的 `scripts/claude_backup.py` 完成（只需要 python3、git、gh）。下文 `$S` 指它的绝对路径。不要自己手写 cp / git 去替代它：脚本里有脱敏、增量、自检、路径重定向等容易漏的逻辑。跟用户说话用大白话。

## 第一次用 / 新电脑 / 新账号：用户说「开始备份」或「从 GitHub 恢复我的 Claude」

1. 检查 `gh auth status`。没有 gh：`brew install gh`（没有 Homebrew 先装 https://brew.sh）。没登录：请用户**自己**在终端运行 `gh auth login`，在浏览器里确认（密码由用户输入，你不要代填）。
2. 运行：
   ```bash
   python3 -I "$S" setup
   ```
   它自己判断：
   - 用户 GitHub 上还没有 `claude-backup` 仓库 → 自动建一个**私有**仓库，开始备份；
   - 已有备份、而这个账号几乎没对话（新账号/新电脑）→ 恢复；
   - 否则 → 继续备份。
   最后都会装好每 10 分钟一次的自动同步（复制到 `~/.claude-backup/bin/` 运行）。
3. 如果做了恢复：告诉用户按 ⌘Q 退出 Claude 再打开，左侧就是以前的对话；连接器需要重新授权。旧账号的原始数据被挪到 `~/Claude旧账号原始数据-日期`，确认没问题后可以删。

## 平时

- 自动同步：`python3 -I "$S" sync`（定时任务在跑，一般不用手动）。上传前会抹掉旧账号的身份信息（账号/组织编号、登录邮箱、设备编号、服务器请求编号、thinking 签名、指向账号的 claude.ai 链接、密钥），自检 0 残留才上传。
- 永远不要用 `backup-raw`（会带着账号信息上传）。
- 状态在 `~/.claude-backup/status.json`；本插件会在输入框下面显示一行「☁️ 备份正常 · 几点同步过 · 多少个对话」。
- 工具更新后运行一次 `python3 -I "$S" schedule`，让定时任务用上新版。
- 30 天自动清理旧对话保持官方默认，不去改。

## 文件夹挪了 / 改名了 / 放进移动硬盘

每个项目文件夹里有一个隐藏小文件 `.claude-folder-id`（身份证，别删；git 仓库里会自动加进 .git/info/exclude）。每次同步会检查：文件夹换了位置或名字，就把对应对话指过去，然后状态栏提醒用户 ⌘Q 重开。恢复到新电脑时也会按身份证找文件夹（用户要整个文件夹拷过去，隐藏文件才会跟着）。
用户说「帮我重新对一下对话的文件夹」：运行 `python3 -I "$S" relink`，提醒用户 ⌘Q 重开。同一张身份证出现在两个地方（复制了文件夹）时不会乱改，只记一条提示。

## 「N 个未备份」：对话太大，等用户决定

GitHub 不收超过 100 MB 的文件。备份遇到这种对话不会悄悄跳过：先不上传，状态行显示「⚠️ N 个未备份（太大，等你决定）」，其他对话照常备份。用户发来这张截图或说「处理未备份的」时：

1. `python3 $S big list` 拿到等待中的文件（名字、大小、路径）。
2. 逐个读对话的开头和结尾几条用户消息、`custom-title`，用一两句大白话说清楚它是干什么的、在哪个文件夹、多大、什么日期。只读，不改。
3. 每个让用户选一种，用户没选的不要替他选：
   - **压缩上传**：`python3 $S big compress <文件名>`。压缩后上传，太大会切块；恢复时自动拼回原样。提醒：这个对话以后每次有变化，会整块重新上传。
   - **不上传**：`python3 $S big skip <文件名>`。电脑上照样留着，只是不传 GitHub，以后不再提醒。
   - **删掉**：先确认一次，再 `python3 $S big delete <文件名>`。对话移到废纸篓，能拿回来；会从 Claude 里消失。
4. 都处理完后跑一次 `python3 $S sync`，状态行变回「☁️ 备份正常」。

A 号、B 号共用同一份备份和同一个选择，选一次两边都算数。

## 要如实告诉用户的

- 带不走：Cowork 任务对话、claude.ai 网页聊天（存在服务器上）。
- 需要重新授权：连接器 / OAuth 类 MCP。
- 抹掉的是本地文件里的账号信息；同一台电脑同一网络，服务器端仍可能把两个账号联系起来。
- 目前只支持 macOS 上的 Claude 桌面 App。
